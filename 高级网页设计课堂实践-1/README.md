# 高级网页设计课堂实践

## 项目目的
本项目旨在展示王垚的《高级网页设计》课堂实践，通过创建多个网页和使用SVG图标，帮助学生掌握现代网页设计的基本技能。

## 项目结构
```
高级网页设计课堂实践
├── index.html          # 包含本目录下所有网页的超链接
├── svg.html            # 包含SVG图标的实现
├── .css
│   └── svg.css         # 与SVG图标相关的样式
└── README.md           # 项目的文档
```

## 使用说明
- `index.html`：此文件是新创建的页面，包含本目录下所有网页的超链接，使用原生代码而不使用CDN。页面主题为王垚的《高级网页设计》课堂实践，包含课堂目录，包括flex复习、字体图标和其他模块（后续增加）。页面经过美化，并包含本提示词。
- `svg.html`：此文件展示了如何使用SVG和字体图标。
- `.css/svg.css`：此文件包含与SVG图标相关的样式，用于美化`svg.html`页面。
