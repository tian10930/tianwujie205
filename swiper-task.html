⭐⭐ 任务一 · 提示词工程师（两轮对话记录）

用提示词让 AI 生成轮播配置

第一轮提示词

“请给我生成一份 Swiper 配置，挂在 #wySw4 容器上：①无缝循环；②每 3.2 秒自动翻页，且我手动拖动之后自动播放不能停；③底部圆点分页器、可以点击跳转；④初始切换效果用 cube 立方体。”

第一轮结论 · AI 首版代码缺了什么

AI 第一版漏了 disableOnInteraction: false——这个选项默认为 true，意味着只要手动拖过一次，自动播放就永久停止，不满足需求②里“手动操作后不停止”；另外它把 effect 写成了默认的 slide，没有按要求用 cube。

第二轮提示词（澄清补齐）

“你给的配置手动拖动后自动播放会停止，请加上拖动后继续自动播放的选项；并把初始效果改成 cube 3D 立方体。”

最终生成的配置（已实测可用）

new Swiper('#wySw4', { loop: true, // ① 无缝循环 speed: 800, autoplay: { delay: 3200, disableOnInteraction: false }, // ② 3.2 秒 + 拖动后不停 pagination: { el: '#wyPag4', clickable: true }, // ③ 圆点可点击 effect: 'cube' // ④ 初始立方体效果 });
💡 一句话总结：提示词必须写清「参数值 + 行为边界」。只说“能自动播放”，AI 就按默认值处理；“拖动之后仍要继续”这种边界条件才是关键。

答辩解答

prev 和 next 的 transform 各控制什么？prev 控制「已经滑过去的上一张」退场后的姿态；next 控制「还没登场的下一张」进场前的姿态。每条里的 translate 是位移（x 横移、y 纵移、z 靠近/远离观察者，z 为负显得缩小、为正显得放大），rotate 是旋转角，shadow 是投影开关。

百分比相对于谁？相对于每张 slide 自身的宽高——x 方向 100% 就是一张照片的宽度，所以 -108% 表示“左移出一屏再多 8%”。

现场把卡片改 20 度：把 rotate: [0, 0, -12] 改成 rotate: [0, 0, -20]（next 的 12 同步改 20），保存刷新即可——上面第二个按钮就是改好 20° 的实测效果。

答辩四连问

① 第六件展品为什么是它？爱达·魔都号是我国首艘国产大型邮轮，2024 年 1 月 1 日首航，与天宫、C919 一样是“从无到有”的大国重器，让光影展覆盖空、天、海、陆。配图为 AI 生成的 16:9 实景图，已本地化保存为 swiper-imgs/aida_1_1.jpg。

② 新增的超纲能力是什么？keyboard 键盘控制——开启后按键盘 ←/→ 即可翻页；onlyInViewport: true 让轮播滚出视野后按键不抢事件，网页照常滚动。

③ 初始化代码怎么写的？在配置对象里加 keyboard: { enabled: true, onlyInViewport: true }，再把 loop、自动播放、圆点分页器一并配上（见下方代码）。

var twjExSwiper = new Swiper('#twjExSw', { loop: true, speed: 700, autoplay: { delay: 2600, disableOnInteraction: false }, pagination: { el: '#twjExPag', clickable: true }, keyboard: { enabled: true, onlyInViewport: true } // 超纲能力：键盘翻页 });

④ 自动播放遇到键盘翻页会怎样？键盘翻页和拖动一样属于用户交互，因为配置了 disableOnInteraction: false，翻页后计时器重置并继续自动播放，不会停摆。
